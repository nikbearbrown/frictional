# Word Counter

A sample project made up for testing Frictional. It is not student work.

Paste text into a web page and get the number of words and the most common word.

## Install

```sh
python -m pip install -r requirements.txt
```

## Run

```sh
python app.py --host 0.0.0.0 --port 8000
```

Then open http://localhost:8000.

## Test

```sh
python -m unittest discover -v
```
