# Word Counter starter

A made-up course starter for `examples/word-counter`, for trying `frictional probe make`. It is not
course material and not student work. `count_words` is given; `most_common` is left for the
student, so the probe treats `most_common` as changed from the starter.

```sh
./frictional probe make examples/word-counter --starter examples/word-counter-starter \
  --out ~/frictional-probe-example --run --deadline 2027-02-14T23:59:00-05:00
```
